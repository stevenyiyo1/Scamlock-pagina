2. Datos que el Bot Procesa

Scam Lock opera bajo el principio de minimización de datos (Zero-Retention):

  • Contenido de Mensajes Analizados: El bot inspecciona en tiempo real los mensajes enviados en canales donde tiene permisos, exclusivamente para detectar enlaces de phishing, estafas conocidas, patrones de ingeniería social y malware.
  • Metadatos Técnicos de Discord: ID de servidor (Guild ID), ID de canal e ID de usuario para aplicar sanciones automáticas (como borrado de mensaje o alerta al equipo de moderación).

3. Almacenamiento y No Retención

  • Procesamiento en Memoria Volátil: El contenido de los mensajes analizados NO se almacena en bases de datos permanentes ni se comparte con terceros con fines publicitarios.
  • Cero Venta de Información: Scam Lock nunca vende, alquila ni comercializa datos de los usuarios o servidores.
